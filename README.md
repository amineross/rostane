# Rostane APT Repository

Add this source in Sileo, Cydia, or Zebra.

```text
https://aminerostane.com/repo
```

- Showcase 1.0 Beta 5 for rootful jailbreaks on iOS 12 or newer, `iphoneos-arm`
- Showcase 1.0 Beta 5 for rootless jailbreaks on iOS 12 or newer, `iphoneos-arm64`
- Showcase for Taurine 1.0 Beta 5, Taurine on iOS 14 only, `iphoneos-arm`
- Share 1.0 Beta 2-5, Personal Hotspot without a SIM, rootful `iphoneos-arm` and rootless `iphoneos-arm64`, iOS 12 or newer

The package manager selects the build that matches the device architecture.
