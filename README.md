# Rostane APT Repository

Add this source in Sileo, Cydia, or Zebra.

```text
https://aminerostane.com/repo
```

- Showcase beta 3 for rootful jailbreaks on iOS 12 or newer, `iphoneos-arm`
- Showcase beta 3-1 for rootless jailbreaks on iOS 12 or newer, `iphoneos-arm64`
- Rootless beta 3-1 selects legacy UART or Apple ConvergedIPC/Skywalk from live hardware properties.

The package manager selects the build that matches the device architecture.
